# 概要

確認日: 2026-11-01。状態: 初期の開発基盤。

一般的なオンラインアプリの使い心地、正しさ、変更容易性、運用負担を評価します。開発者の得意不得意は基準に含めませんが、実装の複雑さやエコシステムの制約は考慮します。

WebはTypeScript／Next.js／PostgreSQL、モバイルはReact Native／Expo、デスクトップはReact／Tauriを初期の推奨とします。全候補に対して実測で優位だったという主張ではありません。

各スターターは自身のlockfileで独立します。Webが参照APIを提供し、クライアントはOpenAPIで記述したHTTP／JSON APIを利用します。DBアクセスはサーバーに置き、端末固有の操作やアクセシビリティは各画面で設計します。

ノート一覧は最新100件までです。ページング、ユーザーごとの所有権、競合解決、永続的なオフラインキューは実アプリで追加します。HTTPの例はローカル開発用で、本番にはHTTPSと認証・認可が必要です。デモAPIは本番環境では拒否します。

実際の確認範囲は[検証記録](evaluations/baseline.md)を参照してください。スターターの存在は、実機検証済み・本番利用可能・性能比較済みという意味ではありません。[開始手順](guides/starting-a-project.md)と[継続更新](guides/maintenance.md)も参照してください。
