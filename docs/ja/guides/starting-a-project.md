# プロジェクトの開始

1. 対象の判断記録と検証上の不足を読み、開始元のリリースタグをcheckoutします。
2. 管理元のルートで`npm ci`、`npm run generate`を実行します。
3. `node scripts/create-app.mjs web ../my-app`を実行します。`mobile`／`desktop`も選べます。出力先は未作成にします。
4. 出力先で`npm ci`を実行し、READMEに従います。lockfileと`.app-foundations.json`を保持します。
5. 名前、パッケージ識別子、画面タイトル、metadata、デプロイ設定を変更します。配布前に`org.example`を置き換えます。
6. 新しいアプリ自身のGitリポジトリを作り、公開範囲を選びます。出力操作だけで公開されることはありません。

モバイル・デスクトップを使う前にWebの参照APIを起動します。iOSシミュレーターは`http://127.0.0.1:3000`、Androidエミュレーターは`http://10.0.2.2:3000`です。実機の通信、TLS、平文通信の制約、認証は別途設定します。認証のないデモを外部公開しません。

実データやデプロイの前に、認証とリソース単位の認可、端末別のセッション／トークン管理、互換性のあるmigration、ページング、rate limit、復元、機密を含まない監視、失敗時の検証を追加します。オフライン対応が必要なら先に競合解決を定義します。これらは初期基盤に実装済みという意味ではありません。
