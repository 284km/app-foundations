# 依存関係の既知事項

確認日: 2026-11-01。初期の開発ツールに残る既知事項です。安全性全般を保証する記録ではありません。

`npm audit`は管理元でmoderate 3件、Expoの依存ツリーでmoderate 21件を報告しました。依存元パッケージへの波及件数も含み、独立した脆弱性の数ではありません。Webとデスクトップのnpmツリーは0件で、四つのツリーにhigh／criticalはありませんでした。件数はlockfileと監査データの変化により変わります。

- [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249): minimatchで攻撃者が制御するパターンによる資源消費。修正はmajor 11です。
- [GHSA-3g3m-2fjr-6pw4](https://github.com/advisories/GHSA-3g3m-2fjr-6pw4): globのタイムアウト後も走査が続く問題。修正版は14.0.2です。

確認できた依存経路はOpenAPI生成とExpoのツールです。ノートAPIは利用者のglobパターンやファイル走査を扱いませんが、全依存経路の到達不能を証明したものではありません。

現在の依存グラフに互換性を維持した自動修正は監査から提示されていません。Expoの対応する組み合わせを保ち、監査表示を消すためだけに未検証の推移依存majorを強制しません。上流の修正を追跡して更新ごとに監査し、利用者がパターンや走査対象を制御する用途を追加する場合は再評価します。未信頼リポジトリの処理や公開の生成サービスは別途評価が必要です。

Rust依存の脆弱性監査は未実施です。Cargoのコンパイルはセキュリティ監査ではありません。
