# Recipes

This directory records application extensions as they become implemented and verified. There are no production-ready extension recipes yet.

Candidates: authentication and per-resource authorization; backward-compatible API evolution; pagination; durable offline queues and conflict resolution; signing and update distribution; backup and restore; privacy-preserving observability.

A recipe must state prerequisites, public references, English/Japanese instructions, code or a runnable example, failure cases, tested platforms, and limitations. Do not present a checklist or placeholder as an implemented feature.
